# Port of Rotterdam Performance Analysis | 2020–2025

An independent data analysis project examining the operational performance of the Port of Rotterdam from 2020 to 2025 using Microsoft Excel and Power BI.

## Project Overview

This project analyzes six years of official Port of Rotterdam data to evaluate changes in total cargo throughput, container activity, cargo composition, and year-over-year performance.

The analysis was developed in Excel and then transformed into an interactive Power BI dashboard containing an overview page and a selected-year analysis page.

## Objectives

- Analyze total port throughput between 2020 and 2025
- Examine container activity using TEU and container throughput
- Compare the development of major cargo categories
- Measure year-over-year changes in port performance
- Identify significant trends across the six-year period
- Build an interactive Power BI dashboard for performance monitoring

## Tools Used

- Microsoft Excel
- Microsoft Power BI
- DAX
- Data visualization
- KPI analysis

## Dataset

The project uses official Port of Rotterdam statistics covering:

- Total Throughput
- TEU
- Containers
- Liquid Bulk
- Dry Bulk
- Breakbulk

Period analyzed: **2020–2025**

## Key Performance Indicators

The dashboard includes:

- Total Throughput
- Total TEU
- Container Share
- Throughput Change 2020–2025
- Year-over-Year Throughput Change

## Key Findings

- Total throughput peaked in 2021 and ended 2025 approximately 1.93% below its 2020 level.
- Container activity recovered in 2024 and 2025 while overall port throughput continued to decline.
- Liquid bulk remained the largest cargo category throughout the analyzed period.
- Dry bulk, liquid bulk, and breakbulk recorded particularly strong volumes in 2022.
- Container share increased from 29.66% in 2023 to 31.09% in 2025.
